# Quality Craft & Visual Excellence Skill

This skill enforces premium standards for UI design and software craftsmanship.

## Aesthetic Requirements

1. **Color Palette**:
   - Deep, cohesive backgrounds (`#0a0b10`, `#0f111a`, `#161822`).
   - Vibrant, tasteful accents (e.g. electric indigo, cyber emerald, glowing violet).
   - Glassmorphism effects with backdrop filters: `backdrop-filter: blur(12px); background: rgba(255, 255, 255, 0.03); border: 1px solid rgba(255, 255, 255, 0.08);`.

2. **Typography & Spacing**:
   - Modern geometric sans-serif (Inter, Outfit, Plus Jakarta Sans).
   - Strict 8-point spatial grid (8px, 16px, 24px, 32px, 48px).

3. **Motion & Feedback**:
   - Smooth micro-interactions for buttons, cards, and inputs.
   - Fluid transitions on hover, focus, and state changes.

4. **Zero-Placeholder Guarantee**:
   - All interactive elements must have real logic or functioning handlers.
   - All text must be authentic and contextual, never placeholder lorem ipsum.
